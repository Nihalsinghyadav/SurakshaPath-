SurakshaPath 🛡️

Personal Safety and Emergency Assistance Web Application

SurakshaPath is a personal safety web application designed to make safety information and emergency assistance features accessible through a simple, user-friendly interface.

Features

- Emergency SOS: An interface for initiating emergency assistance.
- Location Sharing: Location-related features subject to user permissions and device support.
- Trusted Contacts: Manage contacts for safety and emergency communication.
- Route Planning: Tools for planning journeys and exploring routes.
- Interactive Maps: A dedicated map interface.
- Safety Guides: Resources covering personal safety, women's safety, child safety, and public transport safety.
- Voice SOS: Voice-activated emergency functionality, subject to implementation and testing.

Technology

- JavaScript and React
- HTML and CSS
- Location-based web functionality

Purpose

SurakshaPath aims to promote personal safety awareness and make essential safety resources easier to access. The project explores how web technology can support emergency preparedness, safer travel, and communication with trusted contacts.

Important Note

Feature availability depends on implementation, browser permissions, device compatibility, and network connectivity. For immediate emergencies, contact official emergency services.
